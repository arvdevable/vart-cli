thanks for considering contributing to vart.

vart is an experimental identity and article-verification cli.
it is opinionated, unfinished, and open to critique.
this is research-grade software, not production-certified crypto.

vart prioritizes:
- content integrity over convenience
- explicit trust models over implicit magic
- clarity over abstraction

vart is not:
- a decentralized identity system
- revocation-safe
- anonymous
- trustless

we welcome:
- cryptography review and corrections
- threat modeling and attack analysis
- cli ux / dx improvements
- documentation and spec work
- tests and edge-case handling
- refactors for clarity (not premature optimization)

discussion and critique are as valuable as code.
opening issues to question design choices is encouraged.

please avoid:
- introducing new crypto primitives without discussion
- large architectural rewrites without an issue or proposal
- changes that obscure the trust model

by contributing, you agree that:
- your contribution is licensed under the project license (polyform noncommercial 1.0.0)
- you have the right to submit the work

if you need a different arrangement (e.g. commercial or dual licensing),
contact the maintainer before submitting a pull request.
